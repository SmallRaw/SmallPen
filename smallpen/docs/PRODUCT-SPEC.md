# SmallPen 产品规格

更新：2026-09-23。目标行为，不代表全部已实现或已验收。

## Problem Statement

用户通过 Web 和 CLI 编辑同一个本地设计包，需要真实渲染、可靠保存和可恢复错误。
旧卡片混杂需求、实现细节与运行记录，无法直接判断产品应当怎样工作。

## Solution

以 Package canonical 数据为唯一事实来源，让编辑、读取、渲染与重开遵循相同语义。
DS 的展示与编辑边界独立规定于 [DS 规格](DESIGN-SYSTEM-SPEC.md)。

## User Stories

1. 作为设计者，我希望绑定、替换和清除 Token 后立即看到正确效果，以便统一维护样式。
2. 作为设计者，我希望删除被引用 Token 时看到引用位置和解除方法，以免破坏设计。
3. 作为设计者，我希望字面值需要明确确认、匹配值提示复用，以免无意绕过 Token。
4. 作为设计者，我希望路径、描边、箭头、阴影和模糊真实渲染，以便相信画布所见。
5. 作为设计者，我希望布局和文本尺寸随内容变化，以免重叠或裁切。
6. 作为设计者，我希望遮罩、圆角及嵌套裁切正确，以便组合复杂图形。
7. 作为设计者，我希望主组件更新传播到未覆盖实例并保留覆盖，以便安全复用。
8. 作为设计者，我希望创建组件后能从 Assets 放置，以便完成复用流程。
9. 作为设计者，我希望循环引用被拒绝、旧错误可修复，以免文件不可用。
10. 作为设计者，我希望搜索与删除理解真实资源来源，以免改错同名对象。
11. 作为设计者，我希望 Scenario、Context 和 Interaction 与预览一致，以便验证原型。
12. 作为设计者，我希望库清单完整、来源清楚，以便正确选择依赖。
13. 作为设计者，我希望库刷新取得新内容、离线保留可信版本，以便持续工作。
14. 作为设计者，我希望导入图片显示真实像素和透明度，以便评价视觉结果。
15. 作为设计者，我希望字体使用正确字形和字重，并说明格式边界，以免静默替换。
16. 作为自动化使用者，我希望重试幂等、并发冲突可恢复，以免覆盖他人修改。
17. 作为自动化使用者，我希望预演、差异与 watch 行为可信，以便安全编排操作。
18. 作为设计者，我希望切包、多标签及外部修改不串数据，以便并行维护设计。
19. 作为设计者，我希望损坏数据和无效链接提供恢复入口，以免陷入加载页。
20. 作为使用者，我希望发布包和 Desktop 实际可用，以免源码测试通过而交付失败。

## Implementation Decisions

### P1 · Token 与引用

- 公开支持的属性（含 strokeWidth）可绑定、解析、清除并逆向恢复；多描边及类型错误不得部分成功。
- 删除被引用 Token 拒绝提交，列出带 owner 的引用及完整可执行恢复命令，不只提示“解除引用”。
- 字面值确认、匹配 Token 建议、显式解除绑定分开处理，不静默改成 literal。

### P2 · 渲染、布局与文字

- PATH 使用真实 pathData，覆盖相对/绝对命令、闭合、曲线、弧线、复合路径及变换。
- 描边保留 cap/join、端点延伸、虚线实际间隔及箭头方向/颜色，不能用外接框代替路径。
- 阴影正确处理 blur/offset/alpha、负偏移与裁切；layer/background blur 作用于正确区域。
- gap/padding、嵌套 fill/resize、方向与顺序参与真实布局；文本自动高度随内容增减且保留最后一行。
- Emoji 使用真实可用字形或明确诊断；TAB、换行与 rich text runs 不产生额外墨迹。
- mask、show-content、圆角、嵌套旋转裁切遵循实际几何；几何居中与视觉居中分别验证。

### P3 · 组件与原型

- 按批次最终候选图验证自循环和多节点循环，允许合法 DAG；旧循环修复失败也不得部分写入。
- 实例保留 INSTANCE 身份、几何、来源链和 touched overrides；未覆盖部分继承主定义及当前 Context。
- nested、located、ComponentSet variants 保留来源语义；搜索复用建议能实际执行。
- 共享组件删除检查已知消费者、owner 和嵌套引用，不声称发现所有外部消费者。
- Web 创建产生 canonical 组件，可从 Assets 放置并重开；不支持的主节点类型明确报错，不做空操作。
- Scenario 有公开语义读取与渲染，selector 冲突和 Context 覆盖明确；Interaction 元数据对应真实 viewer 导航。

### P4 · Library 与缓存

- 清单涵盖所有贡献 revision；Media、Font、Color、Typography 与组件按 owner 区分，同次响应自洽。
- 外部 Foundation 可移植性、移动和缺失依赖须说明；同名资源不能串 owner。
- 同 URL 刷新实际重新请求并更新依赖；离线或请求失败保留最后可信 snapshot。
- packageID 不符不得替换库；缓存篡改、缺 blob、非法 JSON 不得当作可信版本。
- 在线可重验、离线可诊断，恢复有效源后继续使用，重开能使用可信缓存。

### P5 · Media 与 Font

- 二进制导入当前 Product，内容寻址、去重，删除遵守存活引用；draft fallback 也使用真实位图。
- PNG 保留像素/alpha；JPEG 覆盖声明支持的采样；GIF 正确显示首帧，不暗示支持动画。
- 静态 WebP 有损/alpha 解码在发布包成立；SVG 保留复合路径、曲线、弧线和变换。
- TTF/SFNT 转换保留真实字形；OTF 子类型边界明确；WOFF 验证表和长度完整性。
- WOFF2 区分有效但暂不支持与输入损坏，不能在参数层一概拒绝代替格式判断。
- 未支持或损坏输入给出可操作错误，不用占位图、错字体冒充成功。

### P6 · CLI、事务与恢复

- stale 恢复按刷新、重建、重放处理，保留并发修改与 draft 意图；恢复建议给出完整参数与准确输入要求。
- 同 batchID/内容跨进程幂等，明确后续修改及包移动边界；同 ID 不同内容原子拒绝，覆盖并发/特殊 ID。
- watch 默认持续至停止、尊重 max-events，连续处理无效源到恢复。
- 声明支持写命令的 explain/diff 必须只读，准确列出增删和字段变化。
- 布尔选项位置不影响 flow/page/token；未知选项、缺参数明确失败。
- Node 版本诊断先于 ESM 加载；Unix、Windows 发布入口保持一致。

### P7 · Web 生命周期与兼容

- 同标签新包/最近包切换释放旧 session/库状态；多标签同时编辑不得串 file、revision 或缓存。
- 缺失文件深链接冷/热进入均有持久恢复提示；fileID 不符不得无限加载，随后仍可打开合法包。
- 无效源保留最后有效只读视图和 Repair；重复损坏、恢复及 pending edit 不得导致 draft 静默丢失。
- SmallPen 不可用云历史/共享库菜单及快捷键明确禁用，本地历史和普通 Penpot 不受影响。
- 页面名称未变失焦零 revision；合法前缀原样保留，显示分隔符不写入名称。
- locked/visible、hide-in-viewer、hide-fill-on-export 各作用于对应场景，不互相替代。

## Testing Decisions

- 主链：公开 UI/CLI 操作 → canonical 读回及真实渲染 → Undo/Redo 或逆操作 → 刷新重开。
- 复用既有端到端、source adapter 往返和渲染 fixtures；局部测试只补难触发边界，不按内部函数机械拆分。
- 覆盖 Token、组件、库、媒体字体、事务及 Web 生命周期；具体门槛见 [验收规格](ACCEPTANCE-SPEC.md)。

## Out of Scope

- 不增加第二套数据源、编辑器或历史系统，不为测试绕过产品校验。
- 不承诺全部媒体子格式、GIF 动画、无限外部消费者发现或云能力。
- 本次整理不包含实现修复、发布或 Git 历史操作。
