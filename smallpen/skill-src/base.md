## SmallPen operation rules

Use the supplied CLI path, otherwise `smallpen` on PATH. The CLI's help/schema is complete without a Skill. Discover operations with `help`, then `help OBJECT`, `help OBJECT ACTION`, and the returned schema queries. Read only the action and input fields needed now; use returned IDs, not invented selectors. Put write JSON in files.

Start with one target and compact text. Search large result files with file tools instead of loading the full result into context. Decode JSON text, preserve LF newlines and spaces, and display wireframes in monospace without soft wrapping. Request PNG inspection only when useful and the caller accepts images; a text-only caller may export PNG but must not claim to have inspected it.

Supply a stable batch ID before retryable edits, reuse it only with identical input, and read the write receipt. Follow scoped error recovery and current schemas. An explicit reverse edit is a new guarded write; it is not history rollback. Read check issues, skipped coverage and rendering limits before describing a result as verified.

These are tool rules. The scene below defines how to use the tool for this task.
