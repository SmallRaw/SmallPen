# Use Electron for the SmallPen Desktop shell

SmallPen Desktop will replace its current macOS-only Swift, Cocoa, and WKWebView shell with Electron while retaining the existing Penpot frontend, Local Web Host, Background service, Package model, and multi-window session behavior. The shell uses a top-level `BrowserWindow` rather than Electron's `<webview>` tag, runs the existing Desktop Host in one managed utility process, and does not bundle a second Node runtime. Alpha targets unsigned macOS universal and Windows x64 ZIP artifacts with real smoke tests on both operating systems; macOS may continue treating a `.smallpen` directory as a document package, while Windows opens directory Packages through Home, Open, Recent, or drag-and-drop until a separate single-file or launcher format is explicitly adopted.
